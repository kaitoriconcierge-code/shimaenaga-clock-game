# シマエナガ とけいマスター

iPhone Safari対応の時計学習ゲームです。

## GitHub Pagesで公開
1. GitHubでリポジトリを作成
2. このフォルダ内のファイルをすべてリポジトリ直下へアップロード
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save
7. 発行URLをiPhoneのSafariで開き、共有 → ホーム画面に追加

## 内容
- レベル1：○時
- レベル2：○時・○時半
- レベル3：5分刻み
- レベル4：ミックス
- 5問チャレンジ
- 正解時の音声ほめ
- ホーム画面追加対応
- オフラインキャッシュ対応
